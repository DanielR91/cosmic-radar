# 🛰️ Cosmic Radar Matrix

A real-time HTML5 canvas radar tracking matrix processing over 15,000 active satellites and high-value orbital targets via a raw text TLE ingestion pipeline.

The application dynamically parses complex two-line element sets (TLE) straight from edge-hosted text assets, bypassing typical REST overhead to render thousands of real-time orbital vectors smoothly on a responsive wireframe globe.

## ⚡ Core Features

* **High-Performance Vector Engine:** Renders an active cloud of 15,000+ live spacecraft simultaneously using an optimized HTML5 Canvas animation loop.
* **Raw TLE Stream Ingestion:** Completely migrates from structural JSON overhead to memory-efficient, line-by-line string slicing of standard 3-line raw text blocks.
* **High-Value Target Acquisition:** Integrated strategic intercept panel to isolate iconic deep-space missions instantly, wiping away background data noise.
* **Telemetry Fleet View:** Master tactical override mode to track the top 10 most culturally and scientifically significant spacecraft simultaneously.
* **Starlink Grid Isolation:** Advanced filter matrix to isolate and render SpaceX's massive global low-Earth-orbit communication lattice.
* **Temporal Acceleration:** Built-in dynamic time dilation and compression engine to simulate high-speed orbital passes in real time.
